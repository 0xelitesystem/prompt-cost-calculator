Expected Output (Optional)

Provider
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

How tokens are counted. This tool uses character-based approximation, not the actual tokenizers. Each provider's tokenizer is slightly different (Anthropic uses a BPE variant; OpenAI uses tiktoken; Google uses SentencePiece). The approximation factors used here (chars per token) are calibrated against typical English text and will be within roughly 5 to 15 percent of the real count. For exact counts, use each provider's official tokenizer in their SDK.

Pricing accuracy. Pricing values are baked into this file as USD per 1M tokens. Verify current pricing in the provider's console before relying on the cost estimates for billing decisions. To update, edit the PROVIDERS object at the top of the script.
